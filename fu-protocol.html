Mesh Protocol
Specification.

The validated v3 model, frozen into a wire-level contract. Every clause is reproducible against machine-checkable vectors generated from the Elixir reference. The reference is the oracle; this document is its law.

Authority of this document

Where prose and the conformance vectors (conformance/vectors.json) disagree, the vectors win — they are generated from Fu.Mesh.Identity + Fu.Mesh.V3, the test-locked Elixir reference. A runtime is conformant iff it reproduces every vector exactly.

1 — Scope & status

What is frozen, what is not.

This specifies the trust & sync core: identity, the signed Object, verify-on-receive, expiry/compaction, subject-directed propagation, witnessed rank, and the friendless-bootstrap path. It does not specify radios (BLE/NFC/Wi-Fi-Aware), the PWA, or the node OS layer — those are fu-node.html. Algorithm validated in deterministic simulation to 10,000 users (storage flat, ~100% witness delivery, NFC-feasible payloads; orphan recoverability 90.5% @10k).

3 — Identity

Ed25519, RFC 8032.

  • MUST represent a persona/device as an Ed25519 keypair. Signatures MUST be Ed25519 per RFC 8032 (deterministic — same key + message ⇒ same signature).
  • MUST derive a recoverable identity deterministically from a 32-byte seed (keypair_from_seed); the same seed MUST yield the same public key on any conformant runtime. The 32-byte seed is used directly and unmodified as the Ed25519 private-key seed (RFC 8032 §5.1.5) — no application-level hash/KDF/derivation is applied to the seed before key generation (the SHA-512 expansion of the seed is internal to Ed25519, not an extra step). keypair_from_seed(seed) ≡ the Ed25519 keypair whose private seed is seed. F1 — was implicit (vector-resolved only); now stated. Docs-only, no behaviour change.
  • MUST compute an address as lower_hex(SHA-256(public_key)) truncated to the first 16 hex chars (chars 0–15 — not an inclusive 0..16 range). This is the stable short id.
seed   = 01·32  →  public = 8a88e3dd7409f195fd52db2d3cba5d72ca6709bf1d94121bf3748801b40f6f5c
                    address = 34750f98bd59fcfc        (see vectors.identity[0])
4 — Object & canonical encoding

The exact bytes that get signed.

An attestation asserts a rank delta for a player at a match. Its canonical encoding — the only bytes ever signed or verified — is:

canonical(att) = "{match}|{player}|{delta_milli}"          // UTF-8
delta_milli    = round(delta * 1000)   // round half AWAY from zero; plain integer
// delta=1.5 -> "1|p|1500"   delta=-0.8 -> "7|orphan|-800"   0.1+0.2 -> "2|p|300"
  • MUST sign/verify over exactly canonical(att); fields sig, author_pub, size, witnesses are excluded from the signed bytes.
  • MUST encode delta as the integer round(delta*1000) (round-half-away-from-zero) — never a float string. Removes all cross-language float-formatting divergence; arithmetic noise (0.1+0.2) MUST collapse to the same integer (300). Pinned by the canonical_attestations vectors.
  • MUST treat an Object as immutable and identified by its content; the same canonical bytes are the same Object.
  • MUST treat player as an opaque UTF-8 id that MUST NOT contain the | delimiter.
5 — Verify & ingest

Unverifiable is not state.

  • MUST verify an attestation's Ed25519 signature against its declared author_pub over canonical(att) before any effect (ingest_signed).
  • MUST drop a failed attestation entirely — not fold it, not store it, not relay it. (Vector: forged delta ⇒ knows? = false, rank stays 50.0.)
  • MUST be idempotent by match id: re-ingesting the same Object never double-counts.
  • MUST clamp every derived rank to [30.0, 100.0]; unknown player ⇒ 50.0.
  • MUST compute rank by the explicit fold (F7 — was vector-resolved only; now stated; docs-only): from a checkpoint (base_rank, base_seq) (initially 50.0, 0) plus the pending validly-accepted attestations — rank = clamp( base_rank + Σ a.delta for a in pending ). Application is keyed by match: a match already pending or ≤ base_seq is idempotent (not re-applied); distinct match ids each add their delta exactly once; sum order is irrelevant. Clamp is applied once, to the final folded sum, at read time — intermediate sums are not clamped. Compaction past the window (W = 8) folds the oldest into base_rank clamping per step and advances base_seq; all conformance vectors stay under W, so the observable rule is the single end-clamp.
6 — Expiry & compaction

Bounded by construction (the keystone).

  • MUST retain per known player only the newest W = 8 pending attestations; older ones MUST fold into a (base_rank, base_seq) checkpoint (compact). Per-player store is O(W), not O(history).
  • MUST evict a stranger record after stranger_ttl = 4 idle ticks; friends are permanent; acquaintances are retained while the bond holds.
  • MUST treat a peer as a sustained acquaintance iff encounters ≥ acq_threshold = 3 AND idle ≤ acq_decay = 6; absence (not per-tick erosion) lapses the bond.
Why this is normative, not housekeeping

The flat-storage result holds only because of P6. A runtime that "stores everything for now" is non-conformant by construction — it will reproduce v1's blow-up. Expiry is a correctness invariant: nothing unbounded, ever.

7 — Propagation

Relay toward witnesses; never blind-flood.

On encounter, for each record about subject S, the carrier forwards it to peer T iff:

  • MUST forward when T cares about S (friend of, or already holds S), OR T ∈ S's declared witnesses (subject-directed relay), OR the carrier is close to S (friend/acquaintance).
  • MUST NOT forward a stranger's record to an unrelated peer (closeness filter) — this is what keeps gossip and storage bounded.
  • MUST adopt a more-advanced checkpoint (base_seq) on reconcile and transfer only attestations the receiver lacks; reconcile MUST be convergent and idempotent (a second pass moves 0 bytes).
8 — Witnessed rank

Truth is the witnesses' median, never self.

  • MUST compute a player's canonical rank as the median of that player's witnesses' local views — the player's own copy MUST be excluded.
  • MUST therefore make a lone forger powerless: only the whole witnessing group colluding can move the value. (Vector: witnessed_rank_friends = 51.5 with two honest witnesses; self-tamper to 99.0 has no effect.)
  • MUST return the median element at index div(n-1, 2) of the ascending-sorted views; empty witness set ⇒ 50.0.
9 — Provisional witnesses (bootstrap)

The friendless are recoverable through proximity.

  • MUST treat as a provisional witness of S any node (≠ S) that regards S as a sustained acquaintance AND holds S's record.
  • MUST, when computing recoverable rank, use friend-witnesses if any hold the record; otherwise fall back to the median over provisional witnesses (still self-excluded, still collusion-only).
  • Conformance target (informative): orphan recoverability ≥ ~90% at 10k via this path; the residual tail is a known, accepted limitation (§11).
  • MUST ingest the bootstrap attestation via the unsigned fold (ingest, not ingest_signed) — the friendless path establishes recoverable witnesses from proximity, not authorship. Pinned explicit as scenario.attestation.signed == false (v6).
  • MUST reproduce the section from the pinned scenario bootstrap.scenario (subject · attestation · acq_threshold/acq_decay/ticks · friend_witnesses · per-node friends/encounters_with_subject/ingests_attestation), not from prose. F4 fix (v6): v1–v5 pinned only the outputs; the scenario itself is now contract, so the section is deterministically reproducible and not implementer-invented.
build: for each scenario.nodes[i] → new_node(id,friends); met(subject)×encounters_with_subject;
       if ingests_attestation: ingest(att)    // UNSIGNED fold
vectors.bootstrap.scenario.nodes = [o1·enc3·ingest, o2·enc3·ingest, orphan·enc0·ingest]
  → provisional_witnesses=["o1","o2"]  recoverable_rank=51.5  self_excluded=true
9.5 — Wire framing

The transport boundary, byte-frozen.

A signed Object on a byte stream is one length-delimited, integrity-checked frame. Big-endian throughout. The codec is not security — the digest catches transit bit-rot; Ed25519 (verified?) authenticates.

"FU"     2  magic
0x02     1  frame version (== protocol v2)
type     1  0x01 = signed attestation
len      4  u32, payload bytes, MUST be <= 4096
payload len
digest   4  SHA-256(payload), first 4 bytes (bytes 0–3)   // transit corruption only

payload = match(u32) | delta_milli(i32) | player_len(u16) | player
        | author_pub(32) | sig(64) | wit_count(u16) | [wlen(u16)|witness]*
  • MUST reject len > 4096 (:oversize) before allocating it; reject bad magic (:bad_frame) and frame-version mismatch (:version).
  • MUST treat a frame with fewer than len+4 body bytes as :incomplete — buffer more & retry (this is how MTU chunking & stream reads work); a digest mismatch is a hard :corrupt reject.
  • MUST produce byte-identical frames to the reference for the same signed attestation — pinned by the wire vector (frame_hex). MTU chunking is plain ≤mtu splits whose concatenation is the original frame.
  • MUST keep codec and crypto separate: a structurally-valid frame whose signature fails verified? is decoded but its Object is not state (§5).
9.6 — Pipeline capstone

Convergence using only bytes.

The whole stack as one path: a signer attests about P, the fact reaches witness W1 then is relayed to W2 — and the only channel between nodes is a chunked, reassembled byte stream. No node touches another's state.

sign → canonical → Wire.encode → chunk(mtu_a) → reassemble → decode
     → ingest_signed(W1)  → held_attestations → Wire.encode → chunk(mtu_b)
     → reassemble → decode → ingest_signed(W2) → witnessed_rank == 51.5
  • MUST converge: after the byte-only C→W1→W2 relay, witnessed_rank({W1,W2},["W1","W2"],"P") equals pipeline.final_witnessed_rank — pinned by the pipeline vector.
  • MUST reproduce forged_verified == false: a delta tampered after signing re-frames with a valid digest but a failing Ed25519 check, and is therefore not state. Codec integrity ≠ authorship.
  • This is the closest executable proof of "the protocol runs" obtainable without real radios; the radios remain the genuine remaining build (§11).
9.7 — Adversarial & the security boundary

Where collusion does — and does not — move truth.

The honest security model, stated as testable limits rather than implied. Locked by the adversarial vector.

  • MUST be unmovable by a minority of colluding witnesses: with 5 witnesses and 2 holding a validly-signed inflated fact, witnessed_rank stays the honest median (51.5).
  • MUST be movable by a majority (3 of 5 → 100.0). This is the stated limit, not a defect — trust is group-collusion-bounded, not absolute. Document it; do not "fix" it by trusting fewer parties.
  • MUST preserve integrity against a byzantine relay: a node that mangles a signed Object in transit produces an unverifiable Object that is dropped (byzantine_relay_delivered == false). A relay can withhold (availability) but never inject (integrity).
  • Partition tolerance (informative): a cut-off cluster reads the default until one bridge relay heals it, after which it converges to the witnessed value. Tested in the reference (mesh_adversarial_test).

Regenerate with mix run --no-start bench/conformance_vectors.exs. Bump version on any normative change; a runtime declares which version it targets.

Conformance harness contract

A runtime ships a harness (CI-gated) that loads vectors.json and, per section, performs the operation with its own implementation and asserts equality — exit non-zero on any mismatch. Full procedure: conformance/README.md.

1 assert doc.spec=="fu-mesh-conformance" and doc.version==6   // refuse otherwise
2 identity[]            : keypair_from_seed(seed) → public_hex,address; sign(canonical)→signature_hex
3 canonical_attestations: build canonical(match,player,delta) == .canonical; sign → .signature_hex
4 mesh.signed_ingest    : ingest valid→rank 51.5; ingest forged→not known; witnessed_rank==51.5
5 bootstrap             : provisional_witnesses, recoverable_rank, self_excluded all equal
PASS iff every assertion holds. The harness is the gate, not a courtesy.
11 — Open / non-normative

Honest edges.

  • Wire framing out of scope. SPECIFIED in v3 (§9.5, codec implemented & vector-locked). Still out of scope: the radios themselves (BLE/NFC/Wi-Fi-Aware) and the proximity Anchor — real engineering, node spec.
  • The delta string form risks float-formatting divergence. RESOLVED in v2 — delta is now the integer round(delta*1000) (§4.2); no float formatting crosses the wire.
  • ~10% orphan tail at scale remains unrecoverable in pure phone-only zones; venue nodes (node L1/§01) cover most of it. Mitigated, not zero.
  • Revocation lists, capability tokens & persona↔device key separation are specified at the node layer (L7); their on-wire form is a v2 protocol item.
Bottom line

The trust/sync core is a frozen, vector-checked contract: a future runtime could be verified against it rather than merely inspired. That is the entire claim. No runtime, radio, transport, network, or deployment exists — they are the genuine remaining build, not a thing this document describes as done. One independent implementation (Python) reproduces the vectors but does not, by its own statement, cross the clean-room legitimacy threshold (see redefinition/).
